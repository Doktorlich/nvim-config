# Шпаргалка по конфигу (nvim-config)

`<leader>` = Space. Всегда можно нажать `<leader>` и подождать — LazyVim покажет
which-key подсказку со всеми доступными продолжениями. Это главный способ
"вспомнить" любую комбинацию, не держа всё в голове.

## Базовая навигация по самому LazyVim

| Клавиша | Действие |
|---|---|
| `<leader>` (ждать) | which-key — список всех доступных команд |
| `<leader>x` | `:LazyExtras` — включить/выключить наборы плагинов |
| `<leader>l` | `:Lazy` — статус плагинов, обновления, профилирование старта |
| `<C-/>` / `` <C-\` `` | Терминал внутри Neovim (toggleterm, см. `terminal.lua`) |
| `:checkhealth` | Диагностика всего конфига целиком |
| `:checkhealth <plugin>` | Диагностика конкретного плагина |

## Explorer (snacks_explorer) — `<leader>e`

| Клавиша | Действие |
|---|---|
| `<leader>e` | Открыть/закрыть дерево файлов |
| `a` / `d` / `r` | Добавить / удалить / переименовать файл (внутри дерева) |
| `c` / `x` / `p` | Copy / Cut / Paste |
| `H` | Показать/скрыть скрытые файлы |

## Поиск (Telescope) — `<leader>f*`

| Клавиша | Действие |
|---|---|
| `<leader>ff` | Найти файл |
| `<leader>fg` | Поиск текста по проекту (grep) |
| `<leader>fr` | Recent files |
| `<leader>fp` | Поиск файла внутри установленных плагинов (ваш кастомный keymap) |
| `<leader>U` | История undo с превью (telescope-undo) |

## LSP (vtsls/cssls/html/tailwind/eslint/stylelint/...)

| Клавиша | Действие |
|---|---|
| `gd` | Go to Definition |
| `gr` | References |
| `gI` | Go to Implementation |
| `gy` | Go to Type Definition |
| `K` | Hover (документация) |
| `gK` | Signature Help |
| `<leader>ca` | Code Action |
| `<leader>cr` | Rename |
| `<leader>cR` | Rename File (обновит импорты) |
| `<leader>co` | Organize Imports |
| `<leader>cM` | Add missing imports (только vtsls, TS/JS) |
| `<leader>cD` | Fix all diagnostics (только vtsls) |
| `]d` / `[d` | Следующая / предыдущая ошибка |

**Важно:** namespace-импорт (`import * as x from ...`) auto-import не синтезирует
никогда — это ограничение самого TS language server, не конфига. Только
именованные/дефолтные импорты добавляются автоматически.

## Текстовые объекты (mini.ai / mini.surround)

У вас surround работает через префикс **`gz`** (не стандартный `sa`/`ys`):

| Клавиша | Действие |
|---|---|
| `gza` + объект | Добавить окружение (add surround) |
| `gzd` | Удалить окружение (delete surround) |
| `gzr` | Заменить окружение (replace surround) |
| `gzf` / `gzF` | Найти окружение справа/слева |

mini.ai добавляет расширенные текстовые объекты сверх стандартных `a`/`i`:
`2ai` — второй "внутренний" объект дальше по тексту, `in`/`il` — next/last.

## Общие приёмы, которые реально экономят время

- **`.`** — повторить последнее изменение. Одна из самых недооценённых клавиш в vim вообще.
- **Макросы**: `qa` начать запись в регистр `a`, `q` закончить, `@a` — повторить, `5@a` — повторить 5 раз.
- **Именованные регистры**: `"ayy` — скопировать строку в регистр `a` (не затирая системный clipboard/безымянный регистр), `"ap` — вставить из него.
- **Метки**: `ma` — поставить метку `a` в текущей позиции, `` `a `` — прыгнуть обратно.
- **`gcc`** — закомментировать/раскомментировать строку, `gc` в visual-режиме — блок.
- **`ciw`/`caw`** — change inner/around word — один из самых частых паттернов правки.
- Если забыли, что делает клавиша — **не гадайте**, жмите `<leader>` и читайте which-key,
  либо `:WhichKey <префикс>` для конкретной группы.

## Приёмы для ускорения работы (не просто клавиши, а связки)

- **Harpoon2 вместо Telescope** для 3-5 файлов, с которыми работаете весь день —
  без фаззи-поиска, один прыжок.
- **Leap как motion для операторов**: `ds` + 2 символа = удалить до цели, не считая строк.
- **Quickfix bulk edit**: `<C-q>` в Telescope закидывает результаты в quickfix →
  `:cdo s/old/new/g | update` правит все файлы разом; `]q`/`[q` — навигация по списку.
- **`<leader>cM` → `<leader>co`**: сначала пишете код без импортов вообще,
  потом одной связкой добавляете все недостающие и причёсываете порядок.
- **Snippets по Tab**: не печатать boilerplate руками — только префикс + Tab.
- **`dial.nvim` `<C-a>`/`<C-x>`**: работает не только с числами, но и с `true/false`,
  датами и т.п.
- **`.` (dot-repeat)** после leap-прыжка — для 2-3 повторений быстрее макроса.
- **`<leader>re`** (refactoring.nvim, extract function) — выделили блок в visual,
  сразу получили функцию с вызовом вместо copy-paste вручную.
