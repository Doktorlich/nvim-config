# Шпаргалка по конфигу (nvim-config)

`<leader>` = Space. В любой непонятной ситуации — нажмите `<leader>` и подождите:
which-key покажет все доступные продолжения с описаниями. Это лучший способ
не держать всё в голове.

⚠️ **Важно про ваш конфиг:** стрелки (`<Up>/<Down>/<Left>/<Right>`) отключены
полностью в Normal/Insert/Visual режимах (`lua/config/keymaps.lua`) — двигаться
можно только `h j k l` (или Leap, см. ниже).

---

## 1. Базовое редактирование (стандартный Vim, без изменений в вашем конфиге)

Раз спрашивали "как удалить/вставить" — это НЕ кастомное, это ядро Vim,
но без этого остальное не имеет смысла.

| Клавиша | Действие |
|---|---|
| `i` / `a` | Войти в Insert перед/после курсора |
| `I` / `A` | Войти в Insert в начале/конце строки |
| `o` / `O` | Новая строка снизу/сверху + Insert |
| `x` | Удалить символ под курсором |
| `dd` | Удалить строку целиком (в буфер обмена vim) |
| `dw` | Удалить слово |
| `d$` / `D` | Удалить до конца строки |
| `yy` | Скопировать строку (yank) |
| `yw` | Скопировать слово |
| `p` / `P` | Вставить после/перед курсором |
| `u` / `<C-r>` | Undo / Redo |
| `v` / `V` / `<C-v>` | Visual / Visual Line / Visual Block (выделение) |
| `>>` / `<<` | Сдвинуть строку вправо/влево (в visual — сдвигает выделение) |

**Паттерн "изменить X" = оператор + текстовый объект:**
`d` (delete) / `c` (change) / `y` (yank) / `v` (select) + `i`(inside)/`a`(around) + объект.

| Пример | Что делает |
|---|---|
| `diw` | Удалить слово под курсором (inner word) |
| `ciw` | Заменить слово под курсором (стереть и войти в Insert) |
| `di"` | Удалить содержимое кавычек |
| `da(` | Удалить скобки вместе с содержимым |
| `dap` | Удалить абзац целиком |

## 2. Кастомные текстовые объекты (mini.ai) — "удалить что-то где-то"

У вас настроены объекты СВЕРХ стандартных Vim (`lua/plugins/mini-ai.lua`).
Используются так же: `d`/`c`/`y`/`v` + `i`/`a` + буква объекта.

| Буква | Объект | Пример |
|---|---|---|
| `f` | Функция (через treesitter) | `dif` — удалить тело функции, `daf` — вместе с сигнатурой |
| `c` | Класс | `dac` — удалить класс целиком |
| `o` | Блок/условие/цикл (`if`, `for`, `{}`) | `dio` — удалить содержимое блока |
| `t` | HTML/JSX тег | `dit` — удалить содержимое тега, `dat` — вместе с тегом |
| `d` | Число | `dad` — удалить число под/после курсора |
| `e` | "Слово с учётом регистра" (camelCase-часть) | `cie` на `myVariableName` — заменить только `Variable` |
| `g` | Весь буфер | `dag` — удалить всё содержимое файла |
| `u` | Вызов функции (usage) | `diu` на `foo(a, b)` — удалить `a, b` |
| `U` | Вызов функции без учёта точки в имени | аналогично `u`, для `obj.method(...)` |

## 3. Surround (mini.surround) — окружение кавычками/скобками/тегами

⚠️ У вас нестандартный префикс — **`gz`**, а не привычный `sa`/`ys`.

| Клавиша | Действие |
|---|---|
| `gza` + объект + символ | Добавить окружение, напр. `gzaiw"` — обернуть слово в `"` |
| `gzd` + символ | Удалить окружение, напр. `gzd"` — снять кавычки |
| `gzr` + старый + новый | Заменить окружение, напр. `gzr"'` — `"` → `'` |
| `gzf` / `gzF` | Найти окружение справа / слева от курсора |

## 4. Навигация и перемещение

| Клавиша | Действие |
|---|---|
| `s` + 2 символа | Leap — прыжок в любую точку экрана |
| `S` | Leap — прыжок назад/между окнами |
| Harpoon2 (см. меню которое вы прислали) | `1`-`9` в меню Harpoon — мгновенный переход на закреплённый файл, `H` — добавить текущий файл |
| `<C-a>` / `<C-x>` | dial.nvim — инкремент/декремент (числа, `true/false`, даты) |

## 5. LSP (vtsls / cssls / html / tailwind / eslint / stylelint / ...)

| Клавиша | Действие |
|---|---|
| `gd` | Go to Definition |
| `gr` | References |
| `gI` | Go to Implementation |
| `gy` | Go to Type Definition |
| `K` | Hover — документация от LSP (НЕ `man`, см. отдельно про Keywordprg ниже) |
| `gK` | Signature Help |
| `<leader>ca` | Code Action |
| `<leader>cr` | Rename |
| `<leader>cR` | Rename File (с обновлением импортов) |
| `<leader>co` | Organize Imports |
| `<leader>cM` | Add missing imports (только vtsls, TS/JS) |
| `<leader>cD` | Fix all diagnostics (только vtsls) |
| `]d` / `[d` | Следующая / предыдущая ошибка |

**`K` vs Keywordprg:** `K` у вас переопределён LazyVim на LSP Hover — но это
работает только на символах, которые LSP понимает (переменные, функции,
импорты). Встроенный Vim keywordprg (`man`) остаётся доступен командой
`:!man <слово>` вручную, если когда-нибудь понадобится.

## 11. Приёмы для ускорения работы

- **Harpoon2 вместо Telescope** для 3-5 файлов, с которыми работаете весь день.
- **Leap как motion для операторов**: `ds` + 2 символа = удалить до цели.
- **Quickfix bulk edit**: `<C-q>` в Telescope закидывает результаты в quickfix →
  `:cdo s/old/new/g | update` правит все файлы разом; `]q`/`[q` — навигация.
- **`<leader>cM` → `<leader>co`**: сначала пишете код без импортов вообще,
  потом одной связкой добавляете все недостающие и причёсываете порядок.
- **Snippets по Tab**: не печатать boilerplate руками — только префикс + Tab.
- **`.` (dot-repeat)** после leap-прыжка — для 2-3 повторений быстрее макроса.
- **Extract function** (refactoring.nvim, группа `<leader>r`) — выделили блок
  в visual, точный список действий смотрите через `<leader>r` + which-key,
  т.к. эти бинды приходят из extra `editor.refactoring`, а не из ваших файлов.

## 12. Разделы, которых нет в ваших файлах напрямую

Часть функционала (refactoring.nvim, DAP, aerial/outline, test.core, harpoon2,
leap, dial) включена через `lazyvim.json` extras, а не через отдельные файлы —
точный список их клавиш смотрите через `<leader>` + which-key на месте: у extras
свои дефолтные бинды, которые проще увидеть вживую, чем держать здесь
(и они могут немного меняться между версиями LazyVim).
